Welcome to my recipes webpage! Laid out before you is a repository full of delicious wonders and how to make them.

This project is meant to showcase my skills learned in the **Foundations** section of [**The Odin Project**](https://www.theodinproject.com/about). Among these skills includes:

- Git basics

  - CLI workflow
  - Writing effective commits and commit messages

- HTML basics
  - Usage of basic elements and tags
  - Implementing HTML boilerplate
  - Best practices for folder structure
  - Embedding images
  - Using links for navigation
